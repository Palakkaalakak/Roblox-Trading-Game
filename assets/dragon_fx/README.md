# Dragon fireball textures

Cel-shaded textures for the R/Q/F fire moves, generated by `tools/dragon_fx/make_textures.py`. Re-run that script to regenerate them.

1. In Studio, open View > Asset Manager > Bulk Import and select every `.png` in this folder.
2. Right-click each image > Copy ID, then paste the ID into `src/shared/Dragon/DragonConfig.luau` > `TEXTURES` under the matching name.
3. Sync. Any texture left empty skips its layer, and the geometry still shows.

Files named `*_4x4` / `*_2x2` are flipbooks (16 / 4 frames). White-filled textures (star, ring, slash, lightning, sigil) are tinted per move in code.
